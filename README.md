## テーマ
#季節を感じる地図とは何か  
四季の変化を可視化する地図表現の検討  

## 研究背景
- 日本には四季があり、季節ごとに景観や植生の色彩が大きく変化する
- 地図には多様な情報が表現されているが、季節の変化を視覚的に感じられる地図表現は多くない
- 本研究では、四季の変化を地図上でどのように可視化できるかを整理し、実際に地図を作成することを目標とする

## 研究課題
- 既存の地図サービスでは、季節イベント（桜・紅葉・花火など）が個別に表示されることはあっても、四季の変化を統一的視点で示す例は少ない  
- 衛星画像の季節差や色彩の違いをそのまま地図に反映する仕組みも一般的ではない 
- 「季節を感じる地図」とはどのような表現か、明確な定義がなく検討の余地がある  
- 本研究では、四季の違いが分かる地図表現の可能性を探り、要素を整理する

## 先行事例①：桜前線（日本気象協会）
- 開花予想を地域ごとに色分布や等時線で表示している  
- 色の濃淡やグラデーションが使われ、開花の進み方を連続的に表現  
- 春の景観を示すピンクの色調によって季節感が表現されている

## 先行事例②：紅葉の見頃予想（日本気象協会）
- 各地域の紅葉の進行状況を、灰色〜赤の段階的なマークで表示  
- 色の段階によって、紅葉の進み具合が視覚化されている  
- 秋らしい色調（黄・橙・赤）が用いられている

## 先行事例③：花火アニメーション（Mini Tokyo 3D）
- 花火大会の開催日時に合わせ、地図上に3Dアニメーションを表示  
- 季節イベントを動的に示すことで、夏の季節感を視覚的に伝えている

## 先行事例④：人工衛星画像による季節差（Google Earth）
- 過去の空中写真を年月ごとに閲覧できる  
- 同じ場所でも季節による色彩・植生・明るさの違いが視覚的に確認できる  
- 春・夏・秋・冬で景観が大きく変化し、それが地図表現のベースとなりうる

## 研究方法
1. **四季の特徴整理**  
   - 衛星画像を用いて、春・夏・秋・冬の景観の違い（色・明るさ・植生）を比較  
   - 天気の特徴も整理（春の晴れ、夏の夕立、秋の澄んだ空、冬の雪景色など）

2. **季節らしさの要素抽出**  
   - 色彩、明度、植生、影の強さ、空気感（霞・澄み具合）、天気など  
   - 季節を感じる視覚要素をリスト化

3. **地図デザインの検討**  
   - 上記の特徴をもとに、春・夏・秋・冬の４種類の地図スタイルを設計  
   - Mapbox Studio を用いて、色・明度・線の色・透明度、背景色、モーションなどを調整  
   - 季節らしい見た目の地図を試作する予定

## 季節を感じるための要素
- 桜前線・紅葉・積雪・花火など、季節ごとに異なる地図表現が使われている  
- Google Earthの季節差画像から、同じ場所でも色合い・植生・明るさが大きく変化することが確認できた  
- 四季特有の天気（春の晴れ、夏の雷雨、秋の澄んだ空、冬の雪）が景観の印象を左右する  
- これらより、「色」「明るさ」「植生」「天気」などの視覚的変化を地図のデザインに反映することが重要であると分かった

## 今後の計画
- Google Earth の四季画像を整理し、春・夏・秋・冬それぞれの特徴（色・明るさ・植生・天気）をまとめる  
- 抽出した特徴をもとに、季節らしさを表現するための地図スタイル（春/夏/秋/冬）を作成  
- Mapbox Studio で色・明度・線の色・透明度などを調整し、4種類の地図を試作  
- 春→夏→秋→冬 と切り替えて比較できる形で地図を作成する
